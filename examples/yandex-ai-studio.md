# MnogoReels в Yandex AI Studio (MCP Hub)

Как подключить облачный MCP-сервер MnogoReels к агенту в Yandex AI Studio.

## 1. Получите API-ключ

1. Войдите на https://mnogo-reels.ru.
2. Откройте https://mnogo-reels.ru/dashboard/developers?tab=keys и создайте ключ. Он начинается с `mrfrt_usr_`.
3. Заведите для AI Studio отдельный ключ: так его легко отозвать, не затрагивая другие подключения.

## 2. Добавьте внешний MCP-сервер

1. В AI Studio откройте **MCP Hub** → **Создать MCP-сервер** → **Внешний MCP-сервер**.
2. Заполните поля:
   - **Имя:** `mnogoreels`
   - **URL:** `https://mcp.mnogo-reels.ru/mcp`
   - **Транспорт:** Streamable HTTP
   - **Авторизация:** дополнительный заголовок `Authorization` со значением `Bearer mrfrt_usr_ВАШ_КЛЮЧ`
3. Сохраните сервер. Список из 19 инструментов загружается без ключа, а для вызовов ключ обязателен.

Варианты:

- `https://mcp.mnogo-reels.ru/mcp/readonly` — без инструментов, которые создают задачи и тратят кредиты (13 инструментов).
- Заголовок `X-MnogoReels-Max-Credits-Per-Call: 30` ограничивает расход кредитов на один вызов.
- Если в форме нельзя указать `Authorization`, передайте ключ в заголовке `X-API-Key: mrfrt_usr_ВАШ_КЛЮЧ`.

## 3. Подключите сервер к агенту

Добавьте `mnogoreels` в инструменты агента и проверьте подключение запросом «Вызови get_account»: в ответе должно быть `"authenticated": true`.

## Как агент тратит кредиты

- Платные только `create_clip_job` и `recut_clip_job`: 1 кредит за каждую начатую минуту обрабатываемого отрезка, не больше 30 минут на задачу.
- В инструкции агента пропишите: сначала `quote_clip_job`, показать цену пользователю, после согласия передать `max_credits`.
- Задачи нельзя отменить. Если обработка не удалась, кредиты автоматически не возвращаются; `retry_clip_job` бесплатно перезапускает упавшую задачу, либо напишите на support@mnogo-reels.ru с `job_id`.
- Задачи выполняются в фоне: агент вызывает `get_clip_job` с `wait_sec=50`, пока статус не станет `completed` или `failed`.

## Если не работает

- `invalid_api_key` или HTTP 401 — проверьте ключ и пробел после `Bearer`.
- Пока MnogoReels не запустил отдельную проверку видео для ключей, вызовы без ключа через AI Studio делят общий лимит проверок ссылок с другими пользователями платформы. Всегда указывайте ключ.
- Вопросы: support@mnogo-reels.ru.
